# cli-anything-akshare

CLI for AKShare Chinese financial data library — discover, search, and call any of 673+ AKShare functions from the terminal.

```bash
pip install cli-anything-akshare
cli-anything-akshare --help
cli-anything-akshare list
cli-anything-akshare search 历史行情
cli-anything-akshare call stock_zh_a_hist symbol=000001 period=daily
```

Built with [cli-anything-hub](https://github.com/your-org/cli-anything-hub) methodology.
