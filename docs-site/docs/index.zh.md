# DAAS - 数据即服务

**以技能驱动的金融、经济、统计数据获取平台** —— 一个本地数据平台，把 Python 数据库（`akshare`、`yfinance`、`edgar`、`edinet-tools`、`dartlab`、`world_bank_data`、`ckanapi`）变成一个可查询、可计算指标、可生成看板的数据存储，底层是一个 SQLite 文件（`daas.db`）。

你可以通过 **Claude Code 技能** 或 **统一 MCP 服务器** 来驱动 DAAS —— 两条路径读写同一个数据库。

## 你能做什么

- **浏览上千指标** —— 覆盖公司、行业、城市、国家，包括均线、RSI、波动率、宏观序列等。
- **构建集合** —— 把实体（一个观察列表）和指标（一个可复用集合）分组，成员变动有审计记录。
- **做一项研究** —— 从一个目标到一份持久化研究包：分析 -> 集合 -> 指标 -> 看板 -> Markdown 报告。
- **检视任意实体** —— 查看一只股票/一个国家被哪些数据源覆盖、如何获取。
- **提取并分析财报** —— 拉取财报（EDGAR/EDINET/DART），并在其上计算几十个预置指标。
- **接入你自己的数据源** —— 网站、PDF/文档、数据库 —— 像内置源一样查询。
- **分享看板** —— 通过 WiFi/局域网或公网隧道发布独立 HTML 看板。

## 两种使用方式

| 路径 | 何时使用 |
| --- | --- |
| **技能**（`.claude/skills/`） | 离线友好、最简单。技能直接调用 Python 库 + `sqlite3`。 |
| **MCP 服务器**（`fd-daas-mcp`） | 更丰富 —— 目录浏览、定时任务、告警、看板、编排、PDF 搜索。 |

两者共享同一个 `daas.db`。数据模型见 [概念 -> 实体](concepts/entities.md)，或直接看 [示例](examples/index.md)。
