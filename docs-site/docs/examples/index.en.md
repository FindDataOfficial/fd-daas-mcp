# Examples

Copy-pasteable, fact-checked walkthroughs for the seven canonical DAAS workflows.
Every command resolves against a real skill, MCP tool, or `daas.db` table.

| # | Example | What you learn |
| --- | --- | --- |
| 1 | [Browse Indicators](browse-indicators.md) | Explore the prebuilt indicator catalog across companies/countries. |
| 2 | [Create Collections](create-collections.md) | Build an entity collection + an indicator collection. |
| 3 | [Create a Research](create-research.md) | Turn a goal into a persisted bundle + markdown report. |
| 4 | [Inspect an Entity](inspect-entity.md) | See which datasources cover a stock/country. |
| 5 | [Extract Financial Reports](extract-financials.md) | Pull filings and compute indicators on top. |
| 6 | [Add a Personal Datasource](add-datasource.md) | Bring your own website / document / database. |
| 7 | [Share a Dashboard](share-dashboard.md) | Publish over WiFi/LAN or a public tunnel. |

!!! tip "Skill vs. MCP"
    Each example shows both the **skill** way (natural language in Claude Code)
    and the **MCP** way (direct `<group>_<tool>` calls). Use whichever fits.
