# 示例

可复制、经过核对的 DAAS 七大典型工作流走查。每条命令都对应真实的技能、MCP 工具或 `daas.db` 表。

| # | 示例 | 学到什么 |
| --- | --- | --- |
| 1 | [浏览指标](browse-indicators.md) | 探索覆盖公司/国家的预置指标目录。 |
| 2 | [创建集合](create-collections.md) | 构建一个实体集合 + 一个指标集合。 |
| 3 | [创建研究](create-research.md) | 把一个目标变成持久化研究包 + Markdown 报告。 |
| 4 | [检视实体](inspect-entity.md) | 查看一只股票/一个国家被哪些数据源覆盖。 |
| 5 | [提取财报](extract-financials.md) | 拉取财报并在其上计算指标。 |
| 6 | [添加个人数据源](add-datasource.md) | 接入你自己的网站/文档/数据库。 |
| 7 | [分享看板](share-dashboard.md) | 通过 WiFi/局域网或公网隧道发布。 |

!!! tip "技能 vs. MCP"
    每个示例都给出**技能**方式（Claude Code 自然语言）和 **MCP** 方式（直接调 `<group>_<tool>`）。按场景选用。
