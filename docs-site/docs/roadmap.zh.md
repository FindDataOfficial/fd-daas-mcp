# 路线图

DAAS 公开路线图。条目是方向，不是日期 -- 随项目演进调整。欢迎贡献。

## 投资者与策略

- **更多官方投资者与策略** -- 把精选投资方法（价值、动量、GARP、因子倾斜）做成即用型研究模板和指标集合，让用户能端到端跑一个具名策略。

## 技能

- **更多官方技能** 帮助人们使用平台 -- 把"我有个目标"到"我有看板 + 报告"的门槛降下来。

## 数据源

- **更多官方数据源** -- 扩展源目录（更多交易所、更多宏观提供方、更多另类数据），通过 dispatch 层接入。

## 搜索

- **优化搜索逻辑** -- 更快、更智能的实体/指标/数据源发现（通过 `score` 系统更好排序、模糊匹配、跨源去重）。

## 连接性

- **OpenConnect 支持** -- 在现有代理/隧道路径之外加 OpenConnect 作为网络选项。

## 文档

- **优化文档** -- 保持本站准确、加更多实例、改进搜索与导航。
- **视频课程** -- 为典型工作流制作 walkthrough 视频。

## 商业

- **商业项目功能与商业支持** -- 多租户 / 团队工作流、共享集合，以及面向组织使用的支持方案。

## 量化

- **Nautilus Trader 支持** -- 集成 [Nautilus Trader](https://nautilustrader.io/) 量化框架，让 DAAS 指标能喂给回测/实盘交易。
- **中美关键实体量化优化** -- 为最重要的中国与美国实体（指数、巨头、关键宏观序列）做量化工作流的加固与优化。

## 状态说明

以上是公开路线图的愿景，不是承诺。进行中的工作看仓库 issue 与 `openspec/changes/`。
