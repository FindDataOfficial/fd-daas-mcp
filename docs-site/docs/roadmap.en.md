# Roadmap

The public DAAS roadmap. Items are direction, not dates - they move as the
project evolves. Contributions welcome.

## Investors & strategies

- **More official investors and strategies** - ship curated investment methods
  (value, momentum, GARP, factor tilts) as ready-to-use research templates and
  indicator bundles, so a user can run a named strategy end-to-end.

## Skills

- **More official skills** to help people use the platform - lower the bar from
  "I have a goal" to "I have a dashboard + report."

## Datasources

- **More official datasources** - expand the source catalog (more exchanges,
  more macro providers, more alternative data) wired through the dispatch layer.

## Search

- **Optimize the search logic** - faster, smarter entity/indicator/datasource
  discovery (better ranking via the `score` system, fuzzy matching, cross-source
  dedup).

## Connectivity

- **OpenConnect support** - add OpenConnect as a networking option alongside the
  existing proxy/tunnel paths.

## Documentation

- **Optimize the docs** - keep this site accurate, add more worked examples,
  improve search and navigation.
- **Video lessons** - create walkthrough videos for the canonical workflows.

## Business

- **Business-project features and business support** - multi-tenant / team
  workflows, shared collections, and support offerings for organizational use.

## Quant

- **Nautilus Trader support** - integrate the [Nautilus Trader](https://nautilustrader.io/)
  quant framework so DAAS indicators can feed backtesting/live trading.
- **CN/US key-entity quant optimization** - harden and optimize the most
  important Chinese and US entities (indices, mega-caps, key macro series) for
  quant workflows.

## Status legend

These are aspirations on the public roadmap, not commitments. Check the repo
issues and `openspec/changes/` for in-flight work.
